# Maintenance — 2026-11-14 (M6): the ab1 reference refresh

**What changed and why, in one paragraph.** The M2 verdict
below/in `README.md` was measured in a pre-composer world: at
M2, `--scene ab1` and `--scene-file scenes/ab1.scene.json` ran
the same flat render path, so their pair (95.170 dB) isolated
the format + loader. Two later milestones moved the ground
under the ab1 pair — **M4** reworked the character painter
(the CapFan stroke model), and **M5** gave the hand-authored
ab1 path the full production composer (PBR light rig, PCF-soft
shadows, bloom, GRADE), which format v1 cannot express
(`docs/scene-format.md` §12: the light rig is integration-phase
work). The M2-committed `ab1/original.png` therefore aged out
as a reference. This refresh re-renders both ab1 images from
the current binary and re-states what the pair now measures.
The dof-chart pair needed no refresh and is re-verified
bit-exact below.

## Bisection evidence (painter improvement, not a loader regression)

Produced with the CI binary of run **43509408546** (commit
`b4f9fff`), llvmpipe (LLVM 20.1.2, Mesa 25.2.8) — software
rasteriser; no performance claim.

| comparison | PSNR | mean \|Δ\| | px > 10 | reading |
|---|---|---|---|---|
| current `--scene-file` render vs M2-committed reference | **39.280 dB** | 0.325 | 0.771 % | reproduces the M5 seat's bisection numbers exactly (39.280 / 0.325 / 0.771 %): the drift is the M4 painter rework on the shared canvas, concentrated in the character/grass band |
| current `--scene ab1` (composer) vs M2-committed reference | 21.733 dB | 16.036 | 78.721 % | the M5 composer is the dominant change on the hand-authored path |
| **refreshed ab1 pair** (hand vs file, current binary) | **21.820 dB** | 15.960 | 78.745 % | measures format fidelity **plus** the §12 light-rig/composer gap — it no longer isolates the loader, and is not a regression |
| refreshed dof-chart pair (hand vs file, current binary) | **84.486 dB** | 0.0002 | 0.000 % | identical to the M2 verdict, to the digit |
| current dof `--scene-file` render vs M2-committed `dof-chart/native.png` | **∞ (bit-identical)** | 0.0 | 0.000 % | the loader path is untouched by M4/M5 for the chart |

The logic of the bisection: if the loader had regressed, the
scene-file render would have drifted from its own M2 output
everywhere the format reaches. Instead, the chart's file render
is bit-identical to M2's, the ab1 file render's drift vs the
old reference matches the M5 seat's M4-binary measurement
exactly, and the telemetry proof (docs/ab/telemetry/) shows the
ab1 hand-authored and scene-file stagings producing
byte-identical cutout payloads through the same loader. The
format + loader are as faithful as at M2; the ab1 *scene's two
render paths* diverged because one of them gained a composer
the format cannot yet describe.

## Standing note for future milestones

Until format v2 expresses the light rig (integration phase),
the ab1 pair's PSNR must be read as "composer gap included".
The pure format-fidelity proof is the dof-chart pair plus the
M6 telemetry payload equality. When the rig lands in the
format, expect the ab1 pair to return to the ≥ 84 dB class and
this note to be superseded by a new maintenance entry — not
silently edited away.
