  narration lines cut into **14 shot segments** (S01, S02, S03, S04,

  `frame(t)` seam — Chrome path untouched.
- **Decision (B) governs throughout:** the user decided 2026-11-14
  to keep native frames clean (no q0.93 JPEG generation; recorded in
  the compatibility contract §5, commit `801f85c`). A/B numbers
  against legacy Chrome references are reported, never gated as
  equality.

**Orchestration model.** One lead/integrator seat (spawned before
the wave, folded in at launch) owns the core exclusively —
`src/*.rs`, `src/*.wgsl`, `docs/scene-format.md` — and commits only
its own paths. Wave seats (W01–W100) write only their assigned new
paths, never `src/`, and never commit; the orchestrator validates
and commits centrally between batches. The real parallel ceiling is
~10, so the wave runs as **10 batches of 10**, with the actual agent
count reported against 100 at every batch close.

**Builds law.** This VM has no cargo/rustc and no GPU; all Rust
builds and PBR-path renders verify through GitHub Actions CI
(lavapipe). Every CI verdict is reported the moment it is checked.
No performance claims are made from this VM.

**Rulings landed during the wave** (`docs/scene-format.md` §14.5,
lead commits `5e5b0a0` + `4c06a1e`):

- **R1** — scene-file light blocks carry POST-atmosphere values
  (fire basis 4.6, never the constructor 5.0).
- **R2** — attachments live ON the character node (the loader
  consumes them; the rifle anchors at the painted hand).
- **R3** — GRADE grain time is pinned to 0 in scene files.
- **R4** — source wins over `film.rs` where they diverge.
- **R5** — scene files name atmosphere PRESETS; the driver resolves
  set × preset; the filmLooks table is a derived validation index.

### 2.3 Fog package + verification chart
